# Patent Validation Evidence Bundles

This directory is the default output root for patent-review evidence bundles generated by the local API package.

## Export Command

```bash
PATH=/home/wangfei/.local/node_modules/.bin:$PATH pnpm --filter @agent-safety-gateway/api patent:evidence:export -- \
  --audit-id <audit-id> \
  --bundle-id <bundle-id>
```

Useful selectors:

- `--audit-id <id[,id]>`: include audit records plus context and executor evidence linked to the selected audit ids.
- `--request-id <id[,id]>`: include records linked to selected request ids.
- `--all`: export every local audit, context evidence, side-effect evidence, permit, and denial record.
- `--data-dir <path>`: read from a non-default local store directory instead of `.data`.
- `--out-dir <path>`: override this default output root.

Each generated bundle contains `manifest.json`, `audits.json`, `context-evidence.json`, `side-effect-evidence.json`, `permits.json`, `denials.json`, and a bundle `README.md`.

## Filing Boundary

The export command copies local JSON/JSONL evidence records into reviewable JSON files. It does not replay probes, invoke executors, start local services, connect to production systems, or assert legal claim scope. Counsel-facing claim links are maintained in `docs/patent/claim-mapping.md`.
