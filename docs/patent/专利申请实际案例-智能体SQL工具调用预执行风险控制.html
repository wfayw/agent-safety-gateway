核心保护点：业务无关的执行前控制方法

SQL 删除只是代表性案例。本专利保护的不是某个 SQL 规则，也不是某个审批流程，而是不同业务工具都可以复用的技术链路： 工具调用请求先被拦截，转换为动作元组，再映射到直接和间接受影响资源，生成风险等级，并由执行守卫控制 executor 是否实际调用。

抽象对象 技术含义 SQL 案例 其他业务示例
ToolCallRequest 智能体准备调用工具的原始请求 执行 SQL 调用发布工具、配置工具、CRM API、云资源 API
ActionTuple 统一后的可计算动作 delete + orders + production deploy + service + production；update + creditLimit + production
AffectedResource 本次动作直接影响的资源 orders 表 服务、配置项、客户额度、库存策略、存储桶
ImpactPath 从直接资源传播到间接资源的路径 orders -> 对账任务 配置项 -> 服务链路；客户额度 -> 风控模型
ToolExecutionGuard executor 前的门控执行器 不调用 SQL executor 不调用 deploy executor；路由到 sandbox executor
