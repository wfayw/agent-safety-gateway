## 三、核心实现文件

### 1. 领域模型

文件：

```text
agent-safety-gateway/packages/shared/src/index.ts
```

用途：

- 定义工具类型 `ToolType`。
- 定义操作类型 `OperationType`。
- 定义执行环境 `Environment`。
- 定义风险等级 `RiskLevel`。
- 定义执行决策 `DecisionType`。
- 定义 `ToolCallRequest`、`ActionTuple`、`AffectedResource`、`ResourceDependency`、`RiskFactor`、`ExecutionDecision`、`AuditRecord` 等核心结构。


### 4. 风险评分与决策

文件：

```text
agent-safety-gateway/services/api/src/risk-factor-generator.ts
agent-safety-gateway/services/api/src/risk-level-scorer.ts
agent-safety-gateway/services/api/src/execution-decision-engine.ts
agent-safety-gateway/services/api/src/parameter-rewrite-suggester.ts
```

作用：

- 生成操作、环境、资源级别、依赖影响、验证状态、回滚能力等风险因子。
- 计算风险等级。
- 应用硬阻断规则，例如生产核心表删除、测试失败生产发布。
- 输出执行决策。
- 对高风险操作生成改写建议。

### 5. 执行守卫

文件：

```text
agent-safety-gateway/services/api/src/tool-execution-guard.ts
agent-safety-gateway/services/api/src/mock-tool-executors.ts
agent-safety-gateway/scripts/tool-guard-demo.ts
```

核心逻辑：

- 当 `decision.type = block` 或 `riskLevel = prohibited` 时，不调用 executor。
- 当决策允许且风险不为禁止风险时，调用 executor。
- 返回 `executorInvoked`，用于验证真实执行是否发生。

## 五、四个关键验证场景

### RV-001：生产 SQL 删除阻断

证据文件：

```text
agent-safety-gateway/docs/evidence/real-validation/RV-001-sql-delete-block.md
```

结论：

- Agent Adapter 生成生产 SQL 删除请求。
- 网关识别 `orders` 生产核心表。
- 风险等级为 `prohibited`。
- 决策为 `block`。
- SQL executor 调用次数为 `0`。
- 生成 `SELECT COUNT` 改写建议。

### RV-002：只读 SQL 查询放行

证据文件：

```text
agent-safety-gateway/docs/evidence/real-validation/RV-002-sql-readonly-allow.md
```

结论：

- Agent Adapter 生成只读 SQL 查询。
- 风险等级为 `low`。
- 决策为 `allow`。
- SQL executor 调用次数为 `1`。
- 审计记录保留只读查询证据。

### RV-003：测试失败生产发布阻断

证据文件：

```text
agent-safety-gateway/docs/evidence/real-validation/RV-003-production-release-block.md
```

结论：

- Agent Adapter 生成生产发布请求。
- pipeline fixture 标记测试失败。
- 硬阻断规则生效。
- 风险等级为 `prohibited`。
- 决策为 `block`。
- deploy executor 调用次数为 `0`。

### RV-004：生产关键配置变更进入沙箱建议

证据文件：

```text
agent-safety-gateway/docs/evidence/real-validation/RV-004-production-config-sandbox.md
```

结论：

- Agent Adapter 生成生产配置变更请求。
- 目标配置为 `payment.timeout`。
- 影响 `payment-service` 和 `reconciliation`。
- 风险等级为 `medium`。
- 决策为 `sandbox`。
- production config executor 未直接调用。
- 生成 staging/canary 改写建议。
